Taxi Bahi - programmed landing page

1. Copy app/page.tsx and app/globals.css into your Next.js project.
2. Copy public/taxi-bahi-hero-clean.jpg and public/taxi-bahi-logo.png into public/.
3. Make sure qrcode.react is installed:
   npm install qrcode.react
4. IMPORTANT: do not keep the old TaxiQRCode import/component. This version does not use ./components/TaxiQRCode.
5. Run:
   npm run dev

The QR code is generated from the current page URL in the browser.
